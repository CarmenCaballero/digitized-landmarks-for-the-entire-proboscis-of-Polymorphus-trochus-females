Publicly available digitized landmarks using tpsDig2 for the entire proboscis of Polymorphus trochus females, used in a Geometric Morphometrics Analysis (.TPS). The text files correspond to the host microhabitats: (1) jejunum of F. americana, (2) ileum of F. americana, and (3) ileum of G. galeata. These data were used in the paper: Caballero-Viñas et al. (2019) Acta Zoológica Mexicana, 35, 1–12. https://doi.org/10.21829/azm.2019.3502057"
